# TaskFlow Todo App

A responsive task manager built with React Hooks and CSS Modules.

## Features
- Add, edit, complete, and delete tasks
- Filter all, active, and completed tasks
- Automatically saves tasks in browser `localStorage`
- Task counters and clear-completed action
- Responsive layout

## Run locally
You need Node.js (which includes npm).

```bash
npm install
npm run dev
```

Open the local URL printed by Vite, usually `http://localhost:5173`.

## Production build
```bash
npm run build
```

The production-ready files are generated in `dist/`.

## GitHub
Extract the project ZIP, then upload the project files and folders to your GitHub repository. Do not upload `node_modules` or `dist` unless you specifically need the built output.
